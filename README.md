# 🏦 Bank Management System

A simple web-based Bank Management System developed using HTML, CSS, and JavaScript.

## 🚀 Features

- 🔐 Login System
- 👤 Customer Information
- 🏦 Create New Account
- 🔎 Search Customer Account
- 💰 Deposit Money
- 💸 Withdraw Money
- 🔄 Fund Transfer
- 📋 Transaction History
- 📊 Transaction Summary
- 💾 Data stored using Browser LocalStorage
- 📱 Responsive Design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- GitHub Pages
